# Changelog

## 0.1.0 — 2026-09-21 — entrega de desenvolvimento

Primeira implementação: quatro músicos fixos em arena 3D, ataque automático, prioridade por clique, coleta automática, 18 atos/54 ondas, oito arquétipos, chefes, instrumentos até nível 8, melhorias, Muralha de Som, UI, persistência versionada, arte e áudio procedurais originais.

Inclui cena de entrada, shaders em Resources, ferramentas de validação/build/publicação, testes e documentação de QA. Corrigido durante revisão um retorno de estado após draft esgotado. Testes usam namespace de save independente. Git remoto, compilação Unity, renderização e build de produção não são dados como concluídos.
