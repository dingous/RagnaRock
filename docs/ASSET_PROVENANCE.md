# Procedência e direitos — inventário de entrega

## Gerados para este projeto

Código C#, campanha ficcional, nomes originais dos quatro integrantes, arquitetura, primitivas/meshes, instrumentos, monstros, UI, efeitos, shaders e sintetizador são fornecidos nos arquivos deste projeto. Não foram importados pacotes da Asset Store, fotos, capas, logos de bandas, amostras comerciais, músicas conhecidas ou modelos de outro jogo.

A música é síntese matemática original no arquivo `MetalAudio.cs`. As citações de bandas/títulos são nominais; não há letras, transcrições, covers ou gravações dessas bandas. Não há autorização/endosso representado. As alusões cenográficas são esculturas abstratas próprias e não reproduções de capas.

## Dependências externas

Unity Editor/runtime e pacotes de UI/Test Framework são obtidos pelos seus canais oficiais e permanecem sujeitos às condições próprias. `LegacyRuntime.ttf` é acessada como recurso interno do Unity instalado; **nenhum arquivo de fonte foi incluído neste pacote**. O código não transfere titularidade dessas dependências.

## Licenciamento e nome

Não foi escolhida uma licença pública open-source para o repositório. A entrega do projeto ao solicitante não é uma declaração de exclusividade, registrabilidade ou ausência de conflitos de marca. O nome comercial precisa de revisão: existe um jogo chamado *Ragnarock*. O produto aqui construído é um survivor de defesa de palco e não uma reprodução desse jogo.

Antes de incluir música licenciada, uma marca, modelos externos ou um novo pacote, registrar origem, licença, comprovante de autorização quando aplicável, restrições, autoria e onde o asset é usado. Esta nota não substitui revisão profissional de direitos e distribuição.
